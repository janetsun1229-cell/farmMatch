# Farm Match — 上架技术架构方案

> 目标：上架 Apple App Store 与 Google Play。  
> 客户端：Flutter 一套代码出 iOS / Android。  
> 后台：腾讯云国际站；**仅**内购验单 + 远程配置（无账号、无云存档）。  
> 文档版本：v1.1.1｜2026-10-09｜作者：开发

---

## 1. 目标与边界

| 要做 | 不做 |
|------|------|
| Flutter 双端商店包 | 账号体系 / 登录页 |
| 本机随机身份 + 可改昵称 | Apple / Google / 邮箱登录 |
| 进度、道具、已购权益 **只存本机** | 云存档、进度找回、卸载后恢复业务进度 |
| 内购：道具包、去广告、关卡段解锁包 | 卖单关通关、卖战力、订阅、体力 |
| 后台：IAP 验单 + 远程配置 | 用户进度同步 API |
| 腾讯云国际站部署 API | |

**身份模型（用户 + 策划已定）**

- 首次打开：本地生成 `localUserId` + 随机默认昵称；昵称可改。  
- 关卡进度、道具次数、已购关卡包、去广告：**仅本机**，跟着该身份。  
- **不卸载则保留；卸载后不找回**（不做云端进度）。  
- 后台**不**存用户进度。

> **Restore Purchases（策划已定）**  
> 设置页提供英文按钮 **Restore Purchases**。只恢复非消耗权益：`remove_ads`、`barn_bundle`、`harvest_bundle`。**不恢复**关卡进度、道具次数、昵称。重装后进度仍按「本机、卸载不找回」；已购关卡包/去广告可经商店账号 Restore 拉回本机 entitlements。

## 2. 总体架构

```
┌──────────────────────┐   HTTPS    ┌─────────────────────────┐
│ Flutter App          │ ─────────► │ API（腾讯云国际站）      │
│ 本机身份 / 进度 / 昵称 │            │  /v1/config             │
│ StoreKit2 / Play Billing│──验单──►│  /v1/iap/verify         │
└──────────────────────┘            └───────────┬─────────────┘
                                                │
                                                ▼
                                        Postgres（订单+配置）
```

**栈（已锁定）**

| 层 | 选型 |
|----|------|
| 客户端 | Flutter 3.x |
| 后台 | NestJS（或同等 Node）；接口契约优先于语言 |
| DB | PostgreSQL（订单、配置；无用户进度表） |
| 部署 | **腾讯云国际站**（建议：容器服务 / CVM + 云数据库；HTTPS 证书） |
| 观测 | Firebase Crashlytics + Analytics；服务端日志 |
| HTML 演示 | GitHub Pages 继续独立，与商店包解耦 |

## 3. 客户端（Flutter）

| 模块 | 职责 |
|------|------|
| `identity` | 生成本地 ID、随机昵称、改昵称；Secure Storage / 本地 DB |
| `game` | 玩法、关卡；未解锁关卡段点首页钮 → 购买提示 |
| `inventory` | 道具次数本地增减 |
| `entitlements` | 已购关卡包、去广告；写本地 + 可选商店 Restore |
| `iap` | 发起购买 → 调服务端验单 → 落本地权益 |
| `config` | 启动拉远程配置；失败用内置默认 |

## 4. 内购商品

### 4.1 道具包 + 去广告（策划原定，仍有效）

| SKU | 价格 | 类型 | 内容 |
|-----|------|------|------|
| `pack_small` | $2.99 | 消耗型 | 移出×5、撤回×5、洗牌×5 |
| `pack_medium` | $4.99 | 消耗型 | 各×12 |
| `pack_large` | $9.99 | 消耗型 | 各×30 |
| `remove_ads` | $2.99 | 非消耗 | 终身去广告（可先不上广告，SKU 预留） |

### 4.2 关卡包（策划已定）

| SKU | 价格 | 类型 | 内容 |
|-----|------|------|------|
| `barn_bundle` | $1.99 | 非消耗 | 解锁第 21–35 关 |
| `harvest_bundle` | $2.99 | 非消耗 | 解锁第 36–50 关 |

- 第 **1–20** 关免费。  
- 未买到上限时，首页方钮点击 → 购买提示。  
- 不卖单关通关。

### 4.3 发货流程

1. 客户端商店购买。  
2. `POST /v1/iap/verify`（platform + productId + 收据/purchaseToken）。  
3. 服务端向 Apple/Google 验单；`transactionId`/`orderId` 防重。  
4. 返回验单成功 → **客户端写入本机**权益/道具（服务端可记订单审计，不作为进度源）。  
5. 非消耗：提供 Restore；以商店 + 验单结果刷新本机 entitlements。

## 5. 远程配置

`GET /v1/config?appVersion&platform`

下发：关卡段开关、商品表（含关卡包）、道具数量、`adsEnabled`、文案开关等。失败用客户端内置默认。

## 6. 后台范围（精简）

| 有 | 无 |
|----|-----|
| `GET /v1/config` | `/auth/*` |
| `POST /v1/iap/verify` | `/progress` |
| 订单表（审计、防重放） | 用户表、云存档 |
| 配置表 | Apple/Google 绑定 |

**数据**

- `orders`：platform, product_id, store_txn_id UNIQUE, status, raw, created_at  
- `config`：versioned JSON  

可选：`device_hash` 仅用于限流/风控，不存进度。

---

## 7. 腾讯云国际站部署要点

- 区域：选靠近主要玩家（美国休闲）的国际站点可用区。  
- API：容器或 CVM + 反向代理；强制 HTTPS。  
- DB：云数据库 PostgreSQL；密钥走环境变量 / 密钥管理。  
- 出网：服务端需能访问 Apple / Google 验单端点。  
- 域名 + 证书；配置短 TTL 可加 CDN（可选）。

---

## 8. 安全与合规

- IAP **禁止**只信客户端。  
- 无账号仍需隐私政策（本机数据、分析 SDK、购买）。  
- 限流 verify / config。  
- 年龄分级由市场确认。
